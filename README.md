**Задание:** разработать многостраничный web-сайт на произвольно выбранную тему с использованием технологий HTML и CSS, загрузить проект в репозиторий.

**Выполнение:**
В рамках работы создана папка `Lab2`, в которой реализован многостраничный сайт (4 страницы) на тему «Специальный архив расследований». 

В проекте выполнены все технические требования:
* Использованы HTML-теги строчных и блочных элементов, внедрены гиперссылки, изображения и таблица.
* Оформление вынесено в отдельный подключаемый файл `style.css`.
* Применено более 3 видов CSS-селекторов (по тегу, классу, идентификатору, псевдоклассы).
* Заданы цвета элементов, а также реализовано выравнивание текста в таблице (по левому краю, правому краю и по центру).
* Сторонние библиотеки, фреймворки (Bootstrap) и JavaScript не использовались.
