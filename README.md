# Лабораторная работа № 4

**Цель лабораторной работы:** изучение современного CSS и основ ООП на JavaScript.

**Задание:** на основе web-сайта из лабораторной работы №2 разработать сайт с использованием технологий HTML, CSS и JavaScript и загрузить проект в репозиторий.

**Выполнение:**
В рамках работы создана папка `lab4`, в которую скопирован сайт из лабораторной №2 («Специальный архив расследований») и доработан.

В проекте выполнены все требования:
* Вёрстка с помощью Flexbox — страница `timeline.html` (блок `.timeline`).
* Вёрстка с помощью Grid — страница `classified.html` (блок `.cases`).
* Все цвета в `style.css` заданы только с помощью CSS-переменных (объявлены в `:root`).
* CSS-анимация: появление штампа `.stamp` (`@keyframes stamp-hit`).
* Страница с формой `form.html`: текстовое поле, поле e-mail, выпадающий список, чекбокс-согласие и кнопка отправки.
* В `script.js` создан класс `AccessRequest` с конструктором и методом `print()`. При отправке формы создаётся объект с введёнными данными и вызывается вывод в консоль.
* Стили оформлены по методологии БЭМ (блок, элемент, модификатор).
